# Wedding Berries website

Static multi-page site for GitHub Pages (domain: weddingberriesbd.com). Plain HTML, CSS and vanilla JS.

## Status

| Phase | Status |
|---|---|
| 01 Reference audit | Done, see `docs/reference-audit.md` (browser checks still open) |
| 02 Brand and design system | Done, see `docs/design-system.md` |
| 03 Frontend foundation | Done: 13 pages, shared layout, responsive CSS, mobile menu |
| 04 Animation engine + wedding features | Done (dependency-free, see below) |
| 05 onward | Not started (needs GitHub owner/repo and admin account) |

## Structure

```
index.html ... 404.html     public pages (generated by tools/build_pages.py)
assets/css                  tokens.css, base.css, components.css
assets/js/core/main.js      mobile menu, footer year
assets/js/animations/       core, engine, petals, preloader, interactions
assets/js/features/         gallery (filter + lightbox), countdown
assets/images/              placeholder SVGs (tools/make_placeholders.py)
config/site-config.js       public, non-secret settings only
docs/                       audit and design system
tools/build_pages.py        regenerates all pages from one template
```

## Editing pages

Edit `tools/build_pages.py`, then run `python3 tools/build_pages.py`. Text in `[square brackets]` and boxes labelled "Placeholder" are not real content and must be replaced before launch.

## Rules

No secrets, tokens or keys in this repository. The GitHub App key lives only in the separate broker (Phase 05).

## Animation and features (Phase 04)

Declare effects with data attributes, no JS needed per page:

| Attribute | Effect |
|---|---|
| `data-anim="fade-up / fade-down / fade-left / fade-right / zoom-in"` | Scroll reveal |
| `data-anim="words"` | Masked word-by-word headline reveal |
| `data-anim="clip-up"` | Image curtain reveal |
| `data-delay="0.3"` / `data-stagger="0.12"` | Delay, or stagger a parent's children |
| `data-count="250" data-suffix="+"` | Count-up number |
| `data-parallax="0.07"` | Scroll parallax (put on an inner wrapper, not the reveal element) |
| `data-petals` | Falling rose petals (canvas) inside this container |
| `data-magnetic` / `data-tilt` / `data-burst` | Magnetic button / 3D tilt card / petal burst on click |
| `data-cursor="View"` | Label shown inside the custom cursor |
| `data-timeline` | Scroll-drawn timeline |

Also built in: brand preloader (first visit per session, home only), scroll progress bar, header that hides on scroll down, marquee that speeds up with scrolling, page fade transitions, wedding countdown, filterable masonry gallery with lightbox.

Safety rules: with JavaScript off or `prefers-reduced-motion`, everything is simply visible and no motion runs; a failsafe timer removes hidden states if scripts fail to load.

Note: the master brief names GSAP + ScrollTrigger. This engine is dependency-free with the same declarative API, so GSAP can replace it later without touching page markup.
