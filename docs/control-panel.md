# Control Panel guide

Open `https://<your-site>/admin/` and sign in with your GitHub username, repository, branch and access token.

## Layout

- **Top bar:** View site, Reload from GitHub, Log out.
- **Pills:** Dashboard, then groups: Page text, Content, Site, Design, Tools.
- **Save bar (bottom):** shows "Unsaved changes" and the **Save to GitHub** button. One save = one GitHub commit containing all changed text and photos.

## What you can change

| Group | Sections |
|---|---|
| Page text | Home, About, Services page, Portfolio page, Team page, Testimonials page, FAQ page, Contact page, Menu, Footer, Call-to-action, Privacy and Terms |
| Content | Services (each gets its own page), Projects (each gets a page + gallery), Team, Testimonials, FAQ |
| Site | Brand and logo (logo, dark-background logo, logo size, browser tab icon), Contact info (incl. map and WhatsApp button), Social links, Google and tracking |
| Design | Brand colours (with a readability check), fonts, effects on/off |
| Tools | Launch checklist, Live preview (desktop and phone), Unused files (photos and fonts) |

## Good to know

- Long lists collapse; click a row's title to open it.
- Up/Down arrows reorder items. Delete takes effect when you press Save.
- Photos are resized to max 1800 px before upload. Removed or replaced photos that the panel uploaded are deleted in the same commit.
- If someone else changed the same file on GitHub, the panel refuses to overwrite it and asks you to reload.
- Every save can be undone from the repository history on GitHub.
- Text in `[square brackets]` is placeholder content. The Launch checklist lists what is left.

## Fonts

Design > Colours, fonts and effects has two separate font choices:

- **Display font:** big titles and headings.
- **Writing font:** paragraphs, menu and buttons.

For each one choose **Google Fonts** (about 80 hand-picked fonts: serif, sans-serif, script, decorative and Bangla; pick a style, then a font, and the preview updates) or **Upload my own font file** (WOFF2 is best; WOFF, TTF and OTF also work, up to 4 MB). "Quick font pairs" sets both at once. "Heading size" makes headings larger or smaller (useful for script fonts). Only upload fonts you are licensed to use on a website.

## Logo

Site > Brand and logo: upload the **logo** (transparent PNG or a plain SVG; SVGs with scripts are refused), an optional **logo for dark backgrounds** (used in the footer; if you skip it, the main logo is shown in white), choose the **logo size**, and upload a square **website icon** for the browser tab. The logo is used in the top menu, footer and the opening animation. Tick "Also show the business name" if you want the name next to the logo.
