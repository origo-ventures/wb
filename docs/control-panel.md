# Control Panel guide

Open `https://<your-site>/admin/` and sign in with your GitHub username, repository, branch and access token.

## Layout

- **Top bar:** View site, Reload from GitHub, Log out.
- **Pills:** Dashboard, then groups: Page text, Content, Site, Design, Tools.
- **Save bar (bottom):** shows "Unsaved changes" and the **Save to GitHub** button. One save = one GitHub commit containing all changed text and photos.

## What you can change

| Group | Sections |
|---|---|
| Page text | Home, About, Services page, Portfolio page, Team page, Testimonials page, FAQ page, Contact page, Menu, Footer, Call-to-action, Privacy and Terms |
| Content | Services (each gets its own page), Projects (each gets a page + gallery), Team, Testimonials, FAQ |
| Site | Brand, Contact info (incl. map and WhatsApp button), Social links, Google and tracking |
| Design | Brand colours (with a readability check), font style, effects on/off |
| Tools | Launch checklist, Live preview (desktop and phone), Unused photos |

## Good to know

- Long lists collapse; click a row's title to open it.
- Up/Down arrows reorder items. Delete takes effect when you press Save.
- Photos are resized to max 1800 px before upload. Removed or replaced photos that the panel uploaded are deleted in the same commit.
- If someone else changed the same file on GitHub, the panel refuses to overwrite it and asks you to reload.
- Every save can be undone from the repository history on GitHub.
- Text in `[square brackets]` is placeholder content. The Launch checklist lists what is left.
